# Implementation Plan

## Phase 1 — Repository review ✅

Inspect empty repo; document findings; propose tree.

## Phase 2 — Architecture & docs

Product, architecture, database, matching, security, child safety, moderation, deployment docs.

## Phase 3 — Foundation

Next.js, TS strict, Tailwind, shadcn, Prisma schema, Auth.js, design system, seed data, product config.

## Phase 4 — Accounts & profiles

Multi-step tutor registration; student/parent registration; child profiles; verification upload; admin approval hooks.

## Phase 5 — Marketplace

Search (FTS + filters), tutor public pages, subject pages, online/in-person filters.

## Phase 6 — Requirements

Requirement CRUD; tutor applications; status workflows.

## Phase 7 — Find Your Tutor

12-step questionnaire UI; matching engine; results with explanations.

## Phase 8 — Messaging & reviews

Threads, attachments, parent visibility, reports/blocks, eligibility-gated reviews.

## Phase 9 — Admin

Dashboards for users, tutors, verifications, subjects, prohibited subjects, moderation, matching weights, audit logs, settings.

## Phase 10 — Quality

Vitest + Playwright coverage for acceptance flows; a11y pass; CI; README polish.

## Excluded forever (MVP)

Payments, booking, calendars, classrooms, favourites, trials, analytics payouts — if needed, stop and document rather than implement.
